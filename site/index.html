Conventions

Data at the base point xb (default the equator): c = Taylor constants of Q, γ = U(xb), A = f(xb), κ = fx(xb). The task brief's Γ is γ here, and its γ is κ.

Pole types G / R / L1 / L2 and labels follow the monograph (Table 4.1) and docs/conventions.md.

About this page

This is the browser version of the Swirl Explorer desktop app. The same Python code (solver, pole diagnostics, plots) runs in your browser through Pyodide; nothing is sent to a server. It is about 4–5 times slower than the desktop app, and the Σ-map is shared between several background workers.

Differences from the desktop app: no draggable seed or plane handles (type the values), no arrow glyphs or isosurfaces in 3D, video recording (WebM/MP4 of the 3D view with the caption strip) instead of the composited MP4 export, and a 61 × 61 default Σ-map grid (the desktop uses 101 × 101).

Keyboard: Ctrl+O opens a session, Ctrl+S saves one.
