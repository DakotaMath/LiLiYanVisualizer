Getting started

  • Pick (c₁, c₂) on the plane, drag the c₃ tape and the A bar, and click the green (γ, κ) region: the solution, the 3D view and the profiles follow. Presets jump to the book's examples.
  • With lock to global solutions on, c stays in the Li–Li–Yan set J and (γ, κ) in the global region.
  • The Σ-map tab shows which data are global; click it to jump there, drag a box to zoom in, shift-click to add a path keyframe.
  • Show 2D slice cuts the flow with a plane; Path & movie animates the data along keyframes.
  • Everything runs in your browser; Save session files open in the desktop app too.

Conventions

Data at the base point xb (default the equator): c = Taylor constants of Q, γ = U(xb), A = f(xb), κ = fx(xb). The task brief's Γ is γ here, and its γ is κ.

Pole types G / R / L1 / L2 and labels follow the monograph (Table 4.1) and docs/conventions.md. A red (uncertain) after a pole type means the type was classified with confidence below 0.9: the solution is close to a boundary between types (hover the pole line for the details).

About this page

This is the browser version of the Swirl Explorer desktop app. The same Python code (solver, pole diagnostics, plots) runs in your browser through Pyodide; nothing is sent to a server. It is about 4–5 times slower than the desktop app, and the Σ-map is shared between several background workers.

Differences from the desktop app: no draggable seed or plane handles (type the values), video recording (WebM/MP4 of the 3D view with the caption strip) instead of the composited MP4 export.

Keyboard: Ctrl+O opens a session, Ctrl+S saves one.
